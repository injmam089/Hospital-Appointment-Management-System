**Purpose:** Guide for capturing project report screenshots from the running application  
**Status:** Complete Screenshot Plan  

---

## 1. Screenshot Capture Guidelines

When capturing screenshots for inclusion in the final project report document, adhere to these technical standards:
- **Environment:** Run both services locally (`hams-backend` on port `8055`, `hams-frontend` on port `3000`).
- **Clean Browser Profile:** Use Chrome/Edge Incognito or Playwright browser with 100% zoom.
- **Image Format:** PNG format, compressed losslessly.
- **Recommended Resolutions:**
  - Desktop: `1920x1080` or `1440x900`
  - Tablet: `768x1024`
  - Mobile: `390x844` or `375x812`
